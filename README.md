# Milk Overdose
you are a silly cat in search of some forbidden milk!!
[play it here](https://omnimistic.itch.io/milk-overdose)

# Controls

A and D or left/right arrow keys to move
space to jump/double jump
LMB or X to attack
LMB or X while in air to slam attack
F to throw a tele sword
F again to teleport to tele sword
